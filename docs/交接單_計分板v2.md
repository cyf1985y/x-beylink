# 交接單：計分板 v2（倒數・結束方式・重射・回合時間軸）

日期：2026-08-09｜Supabase 專案：`doeofdyadzkenqiarzre`
資料庫端已完成。

## 為什麼要做

對照 BEYBLADE X 官方賽制，現在的計分板只做了一回合流程的最後一步（判定計分）。
真實流程是：就位 → 裁判喊 3、2、1、Go Shoot → 對戰 → 判定。缺的三塊各自對應
一個實際痛點：

1. 沒有倒數：搶跑爭議靠裁判喊，家長裁判不好意思喊、天梯模式根本沒裁判
2. 只記分數不記贏法：Over 和 Burst 都是 +2，資料上永遠分不出來；選手卡少了
   一整層數據（Xtreme 率、Burst 次數），相關徽章永遠做不出來
3. 沒有重射鈕：發射失誤、同時停止、三秒內無接觸自摔——官方規則都要求不計分
   重來，UI 上卻沒有任何按鈕可按，紀錄上看不出發生過

## 資料庫端（已完成，不用動）

match_points 已升級，現有寫入程式不受影響（新欄位全部 nullable）：

    finish_type      text  null   -- 'spin' | 'over' | 'burst' | 'xtreme'
    reshoot_reason   text  null   -- 'false_start' | 'launch_miss' | 'midair_collision'
                                   --  | 'simultaneous' | 'self_ko' | 'other'
    ladder_match_id  uuid  null   -- 天梯場的回合也寫進同一張表
    match_id         uuid  null   -- （原本 not null，已放寬）
    -- check：match_id 與 ladder_match_id 恰好一個非 null

慣例（DB 不強制，由 app 維持一致）：
- 得分列：finish_type 必填，points = spin:1 / over:2 / burst:2 / xtreme:3
- 重射列：points = 0、side = 0、reshoot_reason 必填
- 修正／復原列：維持現有做法不變，finish_type 留 null

## UI 工作

### 1. 「3、2、1、GO SHOOT」倒數

計分板（裁判模式與計分板模式皆是）加一顆明顯的「▶ 開始回合」鈕：
- 按下 → 全螢幕大字倒數 3 → 2 → 1 → GO SHOOT!，每拍配音效
  （Web Audio 合成即可，不必載音檔；按鈕點擊就是瀏覽器允許出聲的手勢）
- GO SHOOT 之後自動回到計分畫面
- 倒數中誤觸可取消（點畫面任意處）
- 天梯計分板同樣要有——天梯沒有裁判，這顆按鈕就是裁判

### 2. 計分按鈕改為結束方式

把 +1 / +2 / +3 換成四顆（2×2 排列，按鈕要大）：

| 按鈕 | 分數 | finish_type |
|---|---|---|
| 🌀 Spin | +1 | spin |
| 💨 Over | +2 | over |
| 💥 Burst | +2 | burst |
| ⚡ Xtreme | +3 | xtreme |

- 勝負判定邏輯不變（先取 4 分，業務規則不可改）
- 既有的復原／誤判回復流程照舊

### 3. 重射鈕

計分區加一顆中性的「↻ 重射」，按下跳快選：
搶跑｜發射失誤｜空中相撞｜同時結束｜自摔（3 秒內無接觸）｜其他
選完寫入一列 points=0, side=0, reshoot_reason=...，比分不動，回到計分畫面。

### 4. 回合時間軸

對戰頁（賽事 match 頁與天梯 /ladder/match/[id]）顯示逐回合紀錄：

    回合 1  🔴 阿明  ⚡ Xtreme  +3
    回合 2  ↻ 重射（搶跑）
    回合 3  🔵 小華  🌀 Spin   +1

資料就是 match_points 按 created_at 排。復原操作要正確反映在時間軸上。

### 5. 選手卡數據（做得完就順手加，做不完可留）

選手卡「生涯數據」區加：Xtreme 次數、Burst 次數
（從 match_points 聚合，只算 confirmed／done 的場）。徽章不在本單範圍。
