# 自動裁判 現場使用指南（第一次實地測試）

目標：用手機架在戰鬥盤正上方，讓系統即時判出界／極限／轉停並計分；同時把每局影片留下來，回來比對修正。

## 1. 架設

- 戰鬥盤放在箱子底板上（黑底、白盤對比好）。手機用 C 夾加橫臂夾在箱邊，鏡頭對準盤中心正上方，離盤面約 60 公分。
- 開手機相機看一下：整個盤加一圈邊都要在畫面內，鏡頭偏斜不超過 15 度。
- 夾臂要硬、箱子要穩（靠牆或壓重物）。架好之後整場不要再碰手機，鏡頭一動就要重新校正。
- 燈光從上方均勻打，避免透明蓋反光；不要讓人影一直掃過盤面。

## 2. 開啟

- 手機瀏覽器（iPhone 用 Safari、Android 用 Chrome）開 `https://<網址>/autoref`，允許相機。
- 第一次用建議「加入主畫面」，之後全螢幕開啟比較不會誤觸。
- 手機先充飽電或接行動電源，螢幕自動鎖定關掉。

## 3. 校正（每次架好後做一次，約 1 分鐘）

1. 「拍攝空盤背景」：盤內淨空、沒有手，按一下。
2. 對戰區：系統會嘗試自動框，框不準就拖曳頂點貼齊盤內可打的區域。
3. 極限區與左右口袋：拖曳頂點蓋住口袋，極限區要連斜坡一起蓋到。
4. 量陀螺面積：放一顆靜止的陀螺在盤中（手拿開），按「量測」。
5. 儲存。

畫面上方會顯示相機實際幀率與處理幀率，相機盡量是 60、處理至少 25。

## 4. 對戰

- 進「對戰」頁。兩位選手就位、手還在盤上方時狀態是「待機」，發射後手離開自動進入「對戰中」。
- 判定出來會跳判定卡：確認／改判／重賽不計分。爆裂請按「手動爆裂」。
- 系統沒判出來（例如轉停後很快伸手撿），卡片會寫「無法判定」，請用「改判」輸入正確結果，這筆也是修正依據。
- 每一局影片會自動存在手機裡，可在「回放」逐格看與匯出。

## 5. 請幫我留下這些

- 每局：實際結果（出界／極限／轉停／爆裂、誰輸）、系統判定是否一致、有沒有誤判或沒判到。
- 「回放」匯出的影片，或另一支手機從旁側錄的整場影片。
- 相機與處理幀率、手機型號。
- 任何你覺得不順的操作。

回來後把影片和紀錄給我，我拿來重跑、校正、修規則。
